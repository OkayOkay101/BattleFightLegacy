# เครดิต

[English](../en/credits.md) · [สารบัญ](index.md)

ตรวจทาน 2026-10-09 ร่วมกับทะเบียนส่วนประกอบในเครื่อง Editor custom ใช้ภาพเกมเดิมในเครื่อง การตั้งชื่อหรือสร้างชุดค่าสถานะ/อาวุธของผู้ใช้ไม่เปลี่ยนที่มาหรือ license ของภาพต้นฉบับ

## การพัฒนาโดยใช้ AI ช่วย

BattleFight พัฒนาโดยใช้ Gemini Flash และ ChatGPT Sol ช่วยในการพัฒนา

ชื่อเหล่านี้ระบุโดยเจ้าของโปรเจกต์ ไม่เพิ่มเวอร์ชันโมเดล แบ่งหน้าที่ที่ยังไม่ยืนยัน อ้างการรับรองจากผู้ให้บริการ หรือกำหนดความเป็นเจ้าของ เครดิตนี้หมายถึงความช่วยเหลือในการพัฒนา บอทในเกมใช้ heuristic/Neural inference ในเครื่องตาม [คู่มือ AI](ai-training.md)
