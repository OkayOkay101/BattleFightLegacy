# ยูนิตสร้างเอง

[English](../en/custom-units.md) · [เอกสาร](index.md)

อัปเดต **2026-10-09** ตาม source ปัจจุบัน ดู [บันทึกรุ่น](release-notes.md) ว่าพฤติกรรมใดอยู่ใน portable ที่ build ไว้แล้ว

เปิด **ยูนิตสร้างเอง** จากเมนูหลัก เลือกต้นแบบ ตั้งชื่อ เลือด ความเร็ว และอาวุธ แล้วกด **บันทึก** เลือกยูนิตที่บันทึกเพื่อแก้ไข คัดลอก หรือลบ ภาษาเริ่มต้นเป็นอังกฤษ และตัวเลือกภาษาเกมจะแปล editor ด้วย

## ต้นแบบและอาวุธ

รองรับ **44 ตัวละครที่เลือกเล่นได้ในเมนูเดิม** รวม Emo & Sky, Sixth Diva, Roboto และ Zaprytos ไม่รวมตัว unfinished นอกเมนู ยูนิตซัมม่อน ตัวเลือกตัวละคร และต้นแบบเก่าที่ชื่อ Custom Unit รายการต้นแบบแยกจากรายชื่อฝึก production

ทุกช่องเลือกอาวุธประจำตัวเดิมได้ ตัวเลือกเสริม **Stardust Storm** และ **Debris Strike** ถูกนำออกจากรายการอุปกรณ์แล้ว โดยยังคงเป็นอาวุธประจำตัวดั้งเดิมของ PewPew และจะแสดงเป็นตัวเลือกเฉพาะยูนิตเดิมที่บันทึกไว้ก่อนหน้า **อาวุธสร้างเอง** ที่บันทึกไว้ยังใช้ทดลองแทนอุปกรณ์ทุกช่องของร่างหลักได้ทั้ง 44 ต้นแบบ โดย editor เตือนว่าการแทนสกิลที่จำเป็นอาจทำให้การเปลี่ยนร่าง ซัมม่อน หรือระบบทรัพยากรใช้ไม่ได้ ร่างรองคงอาวุธเดิม เมื่อกลับร่างหลักหรือเกิดใหม่จะคืนชุดอาวุธที่บันทึก ยูนิตที่บันทึกไว้เดิมยังใช้ได้ ยังไม่รองรับอัปโหลดภาพ เขียนสคริปต์อิสระ หรือผสมสกิลข้ามตัว

ชื่อยาว 1–80 ตัวอักษร เลือด 1–100000 และความเร็วพื้นฐาน 0–100 ในหน่วยการเดินของเอนจิน โดยศูนย์หมายถึงยืนนิ่งก่อนรับบัฟจากสกิล สกิลเดิมสามารถเปลี่ยนค่าสถานะชั่วคราวได้ editor แสดงค่าต้นแบบให้เปรียบเทียบ

## อาวุธสร้างเอง

เปิดแท็บ **อาวุธสร้างเอง** สร้างหรือเลือกอาวุธ ตั้งรูปแบบการยิงและค่า แล้วกด **บันทึก** การคัดลอกสร้างร่างแก้ไข ต้องบันทึกเพื่อสร้าง ID ใหม่ ระบบห้ามลบอาวุธที่ยูนิตที่บันทึกยังใช้อยู่ ให้เปลี่ยนอาวุธหรือลบยูนิตนั้นก่อน จากนั้นเลือกอาวุธในช่องอุปกรณ์ บันทึกยูนิต และเปิดสนามใหม่

| ค่า | เริ่มต้น | ช่วงที่อนุญาต |
|---|---:|---:|
| ดาเมจต่อเม็ด | 10 | 0–100000 |
| ความเร็วกระสุน (หน่วยเอนจิน) | 20 | 1–200 |
| ระยะเดินทางจากปากกระบอก (พิกเซล) | 800 | 50–5000 |
| คูลดาวน์ (ms) | 500 | 100–10000 |
| จำนวนกระจาย / มุมรวม | 5 / 30° | 1–9 / 0–120° |
| จำนวนนัดต่อชุด / เวลาระหว่างนัด (ms) | 3 / 100 | 1–5 / 50–500 |

ยิงเดี่ยวสร้างกระสุนหนึ่งเม็ด ยิงกระจายสร้างพร้อมกันสมมาตรรอบทิศเล็ง และยิงเป็นชุดตามเวลาโดยใช้ทิศเล็งปัจจุบันของแต่ละนัด คูลดาวน์นับระหว่างเวลาเริ่มยิงแต่ละครั้ง และต้องยาวกว่าเวลาถึงนัดสุดท้ายอย่างน้อย 100 ms ปล่อยปุ่มยิงแล้วยังยิงชุดที่เริ่มไว้จนจบ เปลี่ยนอาวุธ เปลี่ยนร่าง ตาย หรือเริ่มใหม่จะยกเลิกนัดที่เหลือ Heuristic คงอาวุธจนจบชุดและใช้ระยะของอาวุธที่เลือก

ใช้ภาพ Stardust Storm ในเครื่อง ไม่มีเสียง ไม่สืบทอดสคริปต์ดาเมจของกระสุนเดิมหรือโบนัสดาเมจพื้นฐานของผู้ยิง ค่าดาเมจเป็นต่อเม็ดและถูกลดด้วยเกราะเป้าหมาย กระสุนไม่ทะลุ ไม่ทำดาเมจเจ้าของหรือเพื่อนร่วมทีม และหายเมื่อชนศัตรู กำแพง หรือครบระยะ กระสุนกระจายและแต่ละนัดในชุดทำดาเมจแยกกันได้ แต่ callback ซ้ำของกระสุน custom ที่ใช้ไปแล้วไม่เพิ่มดาเมจ สนามจำกัดกระสุน custom ที่ยังอยู่ไว้ 256 เม็ด เมื่อเต็มจะหยุดสร้าง ยกเลิกนัดที่เหลือ และแสดงข้อความ โดยไม่สะสมคิวยิงย้อนหลัง

สคริปต์กระสุนชนยูนิตส่ง event ครั้งเดียวต่อการชนของเอนจิน ภายใต้บริบทเจ้าของกระสุน แก้เส้นทาง Stardust ที่ลดเลือดซ้ำ กระสุนทะลุ ดาเมจต่อเนื่อง และการชนครั้งถัดไปของอาวุธเดิมยังใช้กลไกของตนเอง Damage, assist, kill และ kill feed อิงการเปลี่ยนเลือดจริง

กระสุน custom ที่ยิงไปแล้วเดินทางต่อหลังผู้ยิงตายหรือเปลี่ยนร่าง และเก็บเจ้าของเดิมไว้ให้เครดิต kill ยกเลิกเฉพาะนัดในชุดที่ยังไม่ยิง การเริ่มใหม่ล้างกระสุนเหล่านี้ด้วย Passive ของตัวละครเดิมยังทำงานและอาจสร้างกระสุนเพิ่มเติมของตนเอง แยกจากรูปแบบยิงของอาวุธ custom

ไฟล์อาวุธใช้เวอร์ชัน 1 มี ID `cw-` และ revision อยู่ใน `custom-units/weapons/` รวมถึงภายใต้ userData ของ Electron API CRUD คือ `/api/custom-weapons` ใช้ข้อจำกัด origin ในเครื่องและ token editor เดียวกับยูนิต ไฟล์ยูนิตยังใช้เวอร์ชัน 1 สนามเก็บ snapshot ของอาวุธที่อ้างอิงพร้อม revision การแก้ภายหลังไม่เปลี่ยนสนามที่เปิดอยู่ อาวุธหายหรือเสียหายทำให้ยูนิตที่อ้างอิงไม่พร้อมใช้งาน โดยไม่แทนค่าเงียบ ๆ อาวุธ custom ไม่เข้าระบบฝึก production

## API ในเครื่อง

อ่าน token จากการขอรายการ และส่ง `X-Custom-Unit-Token` พร้อม JSON เมื่อเขียนข้อมูล Request ต้องใช้ origin ของ main server ในเครื่อง สนามแยกไม่เปิด editor สำเร็จตอบ `ok: true` ผิดพลาดตอบ `ok: false` กับ error การแก้/ลบใช้ revision ล่าสุด ถ้าเก่าจะตอบ 409

| Method / endpoint | หน้าที่ / ข้อมูล |
|---|---|
| `GET /api/custom-units` | ยูนิต catalog ข้อมูลรองรับชุดเดิม errors และ token editor |
| `POST /api/custom-units` | สร้าง `{baseId,name,health,speed,weapons}` |
| `PUT /api/custom-units/:id` | แก้ค่าเดิมพร้อม `revision`; เปลี่ยนต้นแบบของรายการเดิมไม่ได้ |
| `DELETE /api/custom-units/:id` | ลบด้วย `{revision}` |
| `GET /api/custom-weapons` | อาวุธ defaults ภาพในเครื่อง errors และ token |
| `POST /api/custom-weapons` | สร้าง name/pattern/damage/speed/range/cooldown และค่ารูปแบบยิง |
| `PUT /api/custom-weapons/:id` | แก้ค่าอาวุธพร้อม `revision` ล่าสุด |
| `DELETE /api/custom-weapons/:id` | ลบด้วย `{revision}`; ห้ามลบเมื่อยูนิตที่บันทึกยังอ้างอิง |
| `POST /api/custom-units/sandbox` | เปิด `{id,controller,opponent}`; controller เป็น `human` หรือ `heuristic` |
| `GET /api/custom-units/sandbox/status` | พอร์ต/URL ของ session หรือ error เริ่ม/รันล่าสุด |
| `POST /api/custom-units/sandbox/:id/stop` | ปิดสนามที่ระบบสร้าง |

สนามแยกมี `/api/custom-sandbox/control` รับ `heartbeat`, `reset` หรือ `stop` ด้วย session token ซึ่งแยกจาก token editor เปิดด้วยพอร์ต loopback อัตโนมัติและรายงาน error โดยไม่ใช้แมตช์หลักร่วม ไฟล์เสียหายแจ้ง error/คำเตือนในรายการ และปฏิเสธข้อมูลขนาดเกินหรือ dependency สูญหาย

## สนามทดลองแยก

บันทึกยูนิต เลือก **ผู้เล่น** หรือ **Heuristic** เลือกคู่ต่อสู้ แล้วกด **เริ่มทดลอง** เว็บต้องอนุญาตป๊อปอัป ส่วน Electron เปิดหน้าต่างแยก สนามใช้พอร์ต loopback สองพอร์ตที่ระบบปฏิบัติการจัดให้ แข่งแบบ 1 ต่อ 1 โดยใช้ตัวที่เลือกไว้ และไม่รบกวนเกมหลัก

ใช้ WASD เมาส์ คลิกซ้าย และปุ่มเลือกอาวุธ 1–4 ใช้กล้องติดตาม/ดูทั้งแมป/กล้องอิสระ และแผงสถิติเดิมได้ **เริ่มใหม่** ล้างยูนิต ซัมม่อน กับดัก กระสุน และงานสกิลที่รอทำงาน แล้วรีเซ็ตยูนิตหลักทั้งสอง คะแนน และสถิติ heuristic ที่เกิดใหม่อาจสร้างซัมม่อนอีกครั้งหลังรีเซ็ต เมื่อตายจะเกิดเป็นตัวเดิมหลังสามวินาที **จบการทดลอง** ปิดเซิร์ฟเวอร์แยก การปิดหน้าต่างทดลองก็หยุดเซิร์ฟเวอร์ และกรณีเว็บขาดการติดต่อจะหมดอายุหลังไม่มี heartbeat สูงสุดประมาณ 90 วินาที

สนามโหลด snapshot ตอนเริ่ม การแก้ไขหรือลบยูนิตที่บันทึกไม่เปลี่ยนการทดลองที่เปิดอยู่ ต้องเริ่มการทดลองใหม่เพื่อใช้ค่าที่แก้ไข เปิดสนามได้ครั้งละหนึ่งสนามต่อเซิร์ฟเวอร์หลัก และสนามที่เลือกผู้เล่นรับผู้ควบคุมจริงหนึ่งคน ไคลเอนต์เพิ่มเติมเป็นผู้ชม

## ที่เก็บข้อมูลและความเข้ากันได้

- เว็บ: `custom-units/` ข้างซอร์สเซิร์ฟเวอร์เกม
- Electron: `custom-units/` ใน userData โดยปกติอยู่ที่ `%APPDATA%/BattleFight/`
- ใช้ `BATTLEFIGHT_CUSTOM_UNITS` เปลี่ยนโฟลเดอร์สำหรับพัฒนาหรือทดสอบในเครื่องได้

JSON แต่ละไฟล์มี `schemaVersion: 1`, ID แยกที่ขึ้นต้น `cu-`, revision, ID ต้นแบบ ชื่อ ค่าสถานะ อาวุธ และเวลาแก้ไข เขียนผ่านไฟล์ชั่วคราวแล้วเปลี่ยนชื่อแบบ atomic การแก้ไขและลบต้องใช้ revision ล่าสุด แจ้งไฟล์เสียหายหรือต้นแบบที่ยังไม่รองรับโดยไม่เขียนทับเงียบ ๆ ไฟล์เหล่านี้ไม่รวมใน Git หรือชุดข้อมูลเริ่มต้นของ portable

editor และ API ควบคุมโปรเซสใช้ได้จากเครื่องเซิร์ฟเวอร์เท่านั้น ต้องใช้ host แบบ loopback และปฏิเสธคำขอข้าม origin การเขียนต้องใช้ session token ของ editor ส่วน WebSocket และรีเซ็ต/หยุดสนามใช้ token แยก WebSocket ต้องใช้ origin ตรงกับสนามด้วย ไม่บันทึก token ในไฟล์ยูนิต

ยูนิต custom และร่างรองมี ID ภาพแยกกัน แต่สถิติดาเมจ kill/assist และการเกิดรวมใต้ custom หลัก สคริปต์เปรียบเทียบตัวตนต้นแบบเฉพาะบริบทที่เกี่ยวข้อง รวมเงื่อนไขไม่โดนตัวเองของ Casker และ Hidden Hand ร่าง SubLazer ใช้เลือดสูงสุดและความเร็วพื้นฐานที่ตั้งไว้ โดยไม่เติมเลือดเพียงเพราะเปลี่ยนร่าง บัฟ ดีบัฟ ทรัพยากร และค่าป้องกันเลือดลดต่ำชั่วคราวของต้นแบบยังทำงาน สนามใช้แอสเซ็ตในเครื่องและไม่มีเสียง ยูนิต custom ไม่เข้ารายการฝึก production และไม่แก้ schema Neural, policy, checkpoint หรือเกณฑ์เปลี่ยน Champion การเปิดฟีเจอร์นี้ไม่เริ่มฝึก

ซอร์สเว็บและ portable ที่ rebuild วันที่ 2026-10-09 มี editor และสนามทดลองนี้แล้ว ไฟล์ portable รุ่นก่อนหน้ายังไม่มีฟีเจอร์นี้

## คำแนะนำสกิล

heuristic ในสนามแยกใช้การเลือกเป้าหมาย เล็ง และเดินตามระบบเดิม พร้อมตรวจทรัพยากรและสถานะก่อนเลือกอาวุธ สกิลที่ทำงานผ่านสคริปต์มีโอกาสใช้แยก Corkmaster หยุดเดินเพื่อใช้สกิลที่ต้องยืนนิ่ง ยกเว้นต้องหลบกระสุนที่กำลังจะโดน ส่วน Tenkai ใช้สคริปต์กระสุน บาเรีย และซัมม่อนเดิม editor แสดงเงื่อนไขทรัพยากร การเปลี่ยนร่าง ซัมม่อน และการยืนนิ่ง คำแนะนำนี้ใช้ในสนามทดลองและไม่เปลี่ยนการตัดสินใจของบอท production

เมื่อเลือกอาวุธกระสุนกลางจะรักษาระยะยิง และกลับไปใช้ระยะต้นแบบเมื่อเลือกอาวุธเดิม SubLazer รักษาเลือดขั้นต่ำ 1 ของร่างแรก เพื่อให้ดาเมจถึงตายเรียกการเปลี่ยนร่างอัตโนมัติได้ ร่างรองคงเลือด 1 ไม่ได้รับการเติมเลือดจากการเปลี่ยนร่าง และมีเลือดขั้นต่ำ 0 เพื่อให้การโจมตีถึงตายครั้งถัดไปฆ่าได้ เมื่อเกิดใหม่กลับเป็น custom หลักที่บันทึก บัฟและดีบัฟคงข้ามร่าง และส่งค่าให้ client หลังอัปเดตประเภทยูนิต
