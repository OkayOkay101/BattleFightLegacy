# บันทึกรุ่นและการตรวจรับ — 2026-10-09

[English](../en/release-notes.md) · [สารบัญ](index.md)

## Source ปัจจุบัน

- Custom Units รองรับต้นฉบับที่เลือกเล่นได้ครบ 44 ตัว มี ID แยก ร่าง ทรัพยากร และสนามผู้เล่น/heuristic
- Custom Weapons เพิ่ม CRUD ในเครื่องแบบมีเวอร์ชัน ตั้งยิงเดี่ยว/กระจาย/เป็นชุด เลือกทุกช่อง snapshot คงที่ และดาเมจจริงบนเซิร์ฟเวอร์
- แก้ event ชนกระสุนที่เรียกสคริปต์ดาเมจซ้ำ กระสุน custom ป้องกัน impact ซ้ำและเก็บเครดิต damage/kill หลังผู้ยิงตาย นัดที่รอยิงยกเลิกเมื่อเปลี่ยนช่วงชีวิต และกระสุนก่อนเฟรมแรกมี deadline ที่ถูกต้อง
- Equipment มีอาวุธประจำตัวกับ custom ที่บันทึก ไม่เสนอ Stardust Storm/Debris Strike เป็นตัวเลือกเสริมข้ามตัว PewPew คงอาวุธเดิมและชุดอุปกรณ์ที่บันทึกก่อนหน้ายังรองรับ ไม่เพิ่มอาวุธประจำตัวซ้ำเป็นตัวเลือกเฉพาะชุดเดิม
- Refresh คู่มืออังกฤษ/ไทย API/การบันทึก เครดิต AI ช่วยพัฒนา และหลักฐาน license ในเครื่อง รายการฝึก production, schema และเกณฑ์ Champion คงเดิม

## หลักฐานและข้อจำกัดการตรวจ

ชุดรวม 508 กรณีของงาน implementation จบด้วยผ่าน 502 ล้มเหลว fixture Stardust สองกรณี และข้ามสี่กรณี opt-in ฝึก/optimizer/CLI สองกรณีนั้นเรียกยิงก่อน clock เอนจินเริ่ม Fixture ถูกแก้ให้รอ clock จริงแล้ว ชุดตรวจซ้ำผ่าน 17/17 รวม Box2D ชนจริง single/spread/burst/native ยังไม่ได้รันคำสั่งเต็ม 508 กรณีซ้ำหลังแก้ fixture

ชุดยาวทั้งสี่ผ่าน ได้แก่ runtime 44 ต้นแบบ ผลสกิลเดิม heuristic อัตโนมัติ และ matrix อาวุธ custom Matrix ตรวจ 173 ช่องร่างหลัก × สามรูปแบบ × สอง controller = 1,038 กรณี พร้อมตาย/เกิดใหม่ 264 กรณี ดาเมจยิงเดี่ยว/กระจายห้าเม็ด/ชุดสามนัดเป็น 10/50/30 การวัด matrix แยกสภาพและส่ง callback ชน ส่วนอีกสี่กรณีใช้การชนที่ Box2D สร้างจริง

Web/Electron จาก source ผ่าน 2/2 และ portable EXE จริงผ่าน 1/1 ครอบคลุม CRUD ภาษา/ร่างที่แก้ ชุดอาวุธที่บันทึก ภาพตัวละคร/กระสุน การเดินและปิดสนาม เป็นการเล่นที่เรนเดอร์จริงด้วยตัวอย่าง ไม่ใช่การเล่น browser แบบ manual 44 รอบ Archive ของ portable ผ่าน 7-Zip ดูรายละเอียดหลักฐานย้อนหลังใน [บันทึก implementation](../superpowers/plans/2026-10-09-custom-weapons-progress.md)
