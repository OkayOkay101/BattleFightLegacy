## 2026-10-20 — Solo Test และ Morrow

Commit `39afe69` บน `codex/battlefight-bots`

- **Solo Test:** สนามแยกที่ไม่มีบอท เลือกได้ทุกตัวละครในเมนูทั้ง 45 ตัว ไม่ต้องมีคัสตอมยูนิตที่บันทึกไว้ มีหุ่นเป้านิ่ง การตาย/เกิดใหม่ ปุ่มเริ่มใหม่ และโปรเซสของตัวเองที่ปิดพร้อม session เมนูจะเปิดเป็น popup (เบราว์เซอร์) หรือผ่าน Electron IPC
- **Morrow:** ตัวละครใหม่ มี Compass Bolt, Banked, หมุดเส้นทางที่หมดอายุใน 7 วินาที และ Atlas (เตือน 800 ms, โดนเป้าละครั้ง, ถูกกำแพงตัด) ยังไม่รวมในการฝึก production และการโคลนเป็นคัสตอมยูนิต
- **แก้ระหว่างตรวจรับ:** ขยายขนาดชนและขนาดภาพของกระสุนกับหมุด, Atlas คงขนาดที่ stream มา, แก้ช่วงแรกของ Banked และการเลี้ยวที่หมุด, เก็บจุดชน raycast ที่ใกล้สุด, ลงทะเบียน timer ของ Morrow ให้ sandbox ล้าง, หุ่นเป้าไม่เกิดทับกัน
- **Sixth Diva และ Emo & Sky:** ทั้ง 8 สกิลยิงออก มีภาพกระสุน และทำดาเมจได้ใน client เบราว์เซอร์จริง การเสียเลือดของ Sixth Diva เป็นต้นทุนที่ออกแบบไว้ (10 HP ต่อใบมีด/นัด; Hexa-Shift แลกเลือดกับความเร็วหรือฮีลชั่วคราว) สกิล 3 และ Brillant Catastrophe ของ Emo & Sky มีดีเลย์ในตัวสูงสุดราว 6.5 วินาที ไฟล์ export ต้นฉบับยังเป็นเวอร์ชันเก่า (สคริปต์ใช้ตำแหน่งไอเทม, URL ภาพภายนอก, ตัวสร้างกระสุนหายเมื่อชน) ส่วน source นี้แก้แล้ว
- **Repository:** คืนค่า `.gitignore` เดิมที่ถูกเขียนทับ และไม่รวมไฟล์ผลลัพธ์ในเครื่อง (backups, reports, dist, video, cache, JSON ผลลัพธ์)

**การตรวจ:** ชุดทดสอบ Solo/Morrow/กระสุนผ่าน 17/17 เมื่อ 2026-10-20 (รอบ QA 2026-10-12 ผ่าน 45/45 ดู [QA ของ Solo Test](../qa/2026-10-12-solo-test.md)) ยังไม่ได้รันชุดเต็มซ้ำ

**แก้ Atlas:** Atlas Unfolded แสดงเส้นเตือนแต่ไม่เคยทำดาเมจ เพราะเกมใช้ physics Planck ซึ่ง `rayCast` รับ `(point1, point2, callback)` แต่ Atlas ส่ง callback เป็นตัวแรก raycast จึงไม่เจอยูนิตและกำแพงไม่ตัดเส้น ตอนนี้ใช้ลำดับของ Planck แล้ว (engine อื่นยังใช้ลำดับ Box2D) และทำดาเมจ 30 ตามที่ตั้งไว้ มี regression test ครอบคลุมลำดับพารามิเตอร์ของ Planck

**Build EXE ใหม่แล้ว:** `dist/portable/BattleFight-Portable-1.0.0.exe` ขนาด 129,138,987 bytes SHA256 `e83138e2f93a95ab1970e219dcc85e3c2dbe0accdcd1db136cbbb720d6c0b8fc` Windows x64 ยังไม่เซ็นดิจิทัล มี Solo Test, Morrow และการแก้ Atlas สคริปต์แพ็กเกจแก้ให้นำภาพ `/assets/morrow` จาก `src/assets/morrow` เหมือนเซิร์ฟเวอร์ source ผล build ไม่มีภาพหาย และไม่มียูนิตที่ใช้ภาพสำรอง ทดสอบ desktop ผ่าน 19/19 และ smoke test ของ Electron ผ่าน 1/1

**ทดลองเล่น EXE:** เล่นผ่านเบราว์เซอร์ที่ต่อกับเซิร์ฟเวอร์ใน EXE โดยส่ง input ผ่านเครือข่ายของเกม โหมด Play Game สู้กับ AI ได้ มี kill feed สด สกิลของ Sixth Diva ยิงออกและเห็นกระสุนครบ ใน Solo Test สกิลทั้ง 4 ของ Emo & Sky มีภาพและทำดาเมจหุ่นเป้า Morrow ทำดาเมจ 12 (Compass Bolt), 22 (Banked Delivery) และ 30 (Atlas) ไม่มี script error ส่วนหน้าต่าง Electron ตรวจด้วย smoke test ไม่ได้เล่นด้วยมือ

## 2026-10-09 — Custom Units และ Custom Weapons

- Custom Units รองรับต้นฉบับที่เลือกเล่นได้ครบ 44 ตัว มี ID แยก ร่าง ทรัพยากร และสนามผู้เล่น/heuristic
- Custom Weapons เพิ่ม CRUD ในเครื่องแบบมีเวอร์ชัน ตั้งยิงเดี่ยว/กระจาย/เป็นชุด เลือกทุกช่อง snapshot คงที่ และดาเมจจริงบนเซิร์ฟเวอร์
- แก้ event ชนกระสุนที่เรียกสคริปต์ดาเมจซ้ำ กระสุน custom ป้องกัน impact ซ้ำและเก็บเครดิต damage/kill หลังผู้ยิงตาย นัดที่รอยิงยกเลิกเมื่อเปลี่ยนช่วงชีวิต และกระสุนก่อนเฟรมแรกมี deadline ที่ถูกต้อง
- Equipment มีอาวุธประจำตัวกับ custom ที่บันทึก ไม่เสนอ Stardust Storm/Debris Strike เป็นตัวเลือกเสริมข้ามตัว PewPew คงอาวุธเดิมและชุดอุปกรณ์ที่บันทึกก่อนหน้ายังรองรับ ไม่เพิ่มอาวุธประจำตัวซ้ำเป็นตัวเลือกเฉพาะชุดเดิม
- Refresh คู่มืออังกฤษ/ไทย API/การบันทึก เครดิต AI ช่วยพัฒนา และหลักฐาน license ในเครื่อง รายการฝึก production, schema และเกณฑ์ Champion คงเดิม

### หลักฐานและข้อจำกัดการตรวจ

ชุดรวม 508 กรณีของงาน implementation จบด้วยผ่าน 502 ล้มเหลว fixture Stardust สองกรณี และข้ามสี่กรณี opt-in ฝึก/optimizer/CLI สองกรณีนั้นเรียกยิงก่อน clock เอนจินเริ่ม Fixture ถูกแก้ให้รอ clock จริงแล้ว ชุดตรวจซ้ำผ่าน 17/17 รวม Box2D ชนจริง single/spread/burst/native ยังไม่ได้รันคำสั่งเต็ม 508 กรณีซ้ำหลังแก้ fixture

ชุดยาวทั้งสี่ผ่าน ได้แก่ runtime 44 ต้นแบบ ผลสกิลเดิม heuristic อัตโนมัติ และ matrix อาวุธ custom Matrix ตรวจ 173 ช่องร่างหลัก × สามรูปแบบ × สอง controller = 1,038 กรณี พร้อมตาย/เกิดใหม่ 264 กรณี ดาเมจยิงเดี่ยว/กระจายห้าเม็ด/ชุดสามนัดเป็น 10/50/30 การวัด matrix แยกสภาพและส่ง callback ชน ส่วนอีกสี่กรณีใช้การชนที่ Box2D สร้างจริง

Web/Electron จาก source ผ่าน 2/2 และ portable EXE จริงผ่าน 1/1 ครอบคลุม CRUD ภาษา/ร่างที่แก้ ชุดอาวุธที่บันทึก ภาพตัวละคร/กระสุน การเดินและปิดสนาม เป็นการเล่นที่เรนเดอร์จริงด้วยตัวอย่าง ไม่ใช่การเล่น browser แบบ manual 44 รอบ Archive ของ portable ผ่าน 7-Zip ดูรายละเอียดหลักฐานย้อนหลังใน [บันทึก implementation](../superpowers/plans/2026-10-09-custom-weapons-progress.md)

แทนช่องสกิลเดิมอาจทำให้กลไกที่พึ่งสกิลนั้นใช้ไม่ได้ และ passive เดิมอาจยิงกระสุน native เพิ่มเอง Custom ใช้เฉพาะสนามทดลองในเครื่อง ช่องว่าง notices และที่มาแอสเซ็ตที่ยังยืนยันไม่ได้อยู่ใน [License](licenses.md) การ build สำเร็จไม่ใช่การให้สิทธิ์ใหม่
