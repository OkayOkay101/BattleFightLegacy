## 1. เป้าหมายและขอบเขต

### 1.1 ทำไมสร้างใหม่ (G)
1. ฝึก AI ได้เร็ว (headless, เร่งเวลา, deterministic)
2. ประสิทธิภาพ/กราฟิกทันสมัยแต่เบา (G2, Q17–Q19)
3. โค้ดดูแลง่าย ไม่ผูก visual script ของ modd.io (Q12)
4. วางขาย/เผยแพร่เองได้ — host modd.io เดิมไม่มีแล้ว (Q37)

### 1.2 สิ่งที่เป็น / ไม่เป็น
- **เป็น:** เกมยิงกระสุนแบบ top-down 2D ออนไลน์ 5v5 บนเว็บ ข้ามแพลตฟอร์ม (Q1, Q6a, Q13) พร้อมโหมดให้ AI agent ของผู้ใช้แข่ง (Q69–Q82)
- **ไม่เป็น:** port 1:1 ของเกมเดิม (Q3), เกมที่ขายของให้ได้เปรียบหรือมีเงินจริงในตอนนี้ (Q42), เกมที่ใช้ rollback netcode (Q8)

## 2. สถาปัตยกรรม

```
                 ┌──────────────── packages/sim (TS, source-available) ────────────────┐
                 │ ECS เบา · physics เอง · 30 Hz · RNG (seed ลับ) · serialize ทั้งหมด      │
                 │ CC · heat · buffer/queue · targeting · rewind · obs/action API        │
                 └───────▲───────────────▲───────────────▲───────────────▲─────────────┘
                         │               │               │               │
   apps/web ── client (Pixi v8 + HUD)    server (Colyseus)    bot-runtime (ONNX)   training/ (Python)
   apps/desktop (Tauri)  + ui (Preact)   authoritative,       batch inference      Gym/PettingZoo,
   apps/mobile (Capacitor/PWA)           interest mgmt        ทุก 2–3 tick          self-play
                                         replay/snapshot 20Hz
```

### 2.1 Stack (Q6b, Q7, Q14, Q318)
TypeScript strict ทั้งระบบ, pnpm workspaces, Vite, Vitest, Biome, Node LTS (อัปเกรดปีละครั้ง), Zod, PixiJS v8 (WebGPU → WebGL2), Colyseus, bitecs หรือ ECS เอง, onnxruntime-node, Python + uv สำหรับฝึก, Capacitor/PWA, Tauri

### 2.2 โครง repo `battlefight-ts` (Q317)
```
packages/ sim/ data/ content-tools/ client/ ui/ server/ bot-runtime/ benchmark/
apps/     web/ desktop/ mobile/ admin/
training/ assets/ docs/
```
- `packages/sim` ห้าม import แพ็กเกจอื่นในโปรเจกต์ (เปิดซอร์สแยกได้ — Q74, Q80)
- `taro-engine/` เดิมเก็บเป็นต้นฉบับอ้างอิง ต้อง commit/archive ก่อนเริ่ม (Q27)

### 2.3 Sim core
- **Tick:** sim 30 Hz, ส่งผู้เล่น 20 Hz (ลดเหลือ 10–15 Hz อัตโนมัติเมื่อเน็ตช้า) (Q83, Q329)
- **Physics เอง:** วงกลม/กล่อง/raycast, กระสุนสะท้อน, ผลัก/ดึงระยะตายตัว ชนกำแพงแค่หยุด (Q7, Q246, Q217)
- **RNG:** seed ลับบนเซิร์ฟ ไคลเอนต์ไม่ทำนายผลสุ่ม; seed ลงไฟล์ replay หลังจบแมตช์; เปลี่ยน seed ทุกครั้งที่มีการย้อน (Q344, Q482, Q514)
- **Snapshot:** สถานะครบทุกอย่าง 20 Hz delta-compressed — สตรีมเดียวใช้กับผู้เล่น, ผู้ชม, replay, การกลับเข้าแมตช์, rewind (Q65)
- **Observation/action API:** ชุดเดียวใช้กับบอท ระบบฝึก และ agent (Q82)
- **ID ต่อผู้ดู:** ศัตรูมี ID ชั่วคราวเฉพาะผู้ดูและเฉพาะที่มองเห็น (Q413)

### 2.4 Netcode (Q8, Q326–Q330, Q359)
- Server-authoritative + client prediction + interpolation ปรับตาม jitter
- Lag compensation **เฉพาะสกิล hitscan** สูงสุด 200 ms; projectile ไม่ย้อนเวลา
- WebSocket ก่อน → WebTransport/WebRTC datagram + fallback
- ส่งคำสั่ง 3–5 รอบล่าสุดซ้ำทุกแพ็กเก็ต; คำสั่งเวลาเก่าเกินกำหนดถูกปฏิเสธ คำสั่งช้าทำงาน ณ เวลาที่มาถึง (Q327, Q334)
- ไม่มี P2P ใดๆ (Q424)

### 2.5 Interest management (P3)
เซิร์ฟคำนวณ "สิ่งที่จอผู้เล่นคนนี้แสดง" ต่อ tick แล้วส่งเฉพาะสิ่งนั้น ครอบคลุม: นอกระยะซูมสูงสุด (Q196), หลังกำแพง, ล่องหน/พุ่มไม้ (Q342), blind ทุกรูปแบบรวมระดับทีม (Q257, Q432–Q433), เสียงตามที่สกิลกำหนด (Q343), fake telegraph ไม่บอกจริง/หลอก (Q363), cooldown/perk/macro ของศัตรูที่ไม่แสดง (Q449), snapshot ระหว่างแมตช์ทุกจุด (Q358) — **มีเทสต์อัตโนมัติตรวจข้อมูลเกิน** (Q364)

## 3. เกมเพลย์

| สนามฝึก / เล่นกับบอท / ห้องส่วนตัว | — | beta |

**R-5v5:** แมตช์ 5v5 เสมอ 1 บัญชี = 1 ช่อง; ไม่พอเติมบอทและ**แจ้งผู้เล่นก่อนเริ่ม** (Q466); ranked ไม่มีบอท (Q471)

### 3.2 ตัวละคร
- **Roster v1 (12):** Gavin the Archmage, Nadia, Berserker, Commander, Crackshot, Alchemist, Hidden Hand, Bush Man, Ming, Shinobi, Shadow Dancer, Sixth Diva — ผู้ใช้ยืนยันเป็นเจ้าของทั้งหมด (Q233, Q238, Q292); ตรวจชื่อสกิลซ้ำเกมอื่นแบบเบาก่อน beta
- **หลัง beta:** ทยอย ~1–2 ตัว/เดือน รวมตัวหลายร่าง/เรียกลูกน้อง (Q235, Q240); healer ผู้ใช้ออกแบบภายหลัง (Q239)
- **ตัวที่อ้างอิงงานคนอื่น:** ออกแบบใหม่ (ชื่อ/หน้าตา/สกิลชื่อ/เรื่อง) คงกลไก (Q30, Q45)
- **แท็กแบบ Dota ระดับ 1–5** (Q140, Q214); ระดับความยาก 1–3 ดาว (Q203); ห้ามซ้ำในทีม (Q88)
- **ตัวละคร 2 ผู้เล่น:** กิน 2 ช่อง, ผู้เล่น 2 คนในทีมต้องยอมรับ (ปกติขอบอทเป็นคู่ได้, ranked ต้องคน 2 คน), ระบบรองรับ 3 รูปแบบ; คู่หลุด: โคลน/อีกคนคุมทั้งคู่ (หลังแมตช์ผ่าน ~60 วิ)/คนในคิว (Q434–Q441, R-5v5, Q467, Q468)
- **ท่าไม้ตาย:** ไม่บังคับ แยกตัวที่มี/ไม่มี (Q219, Q227)

### 3.3 Gavin, the Archmage (ตัวอย่างอ้างอิง) — Q212–Q231
สลับเวท 4 ธาตุ (Arcane Inferno / Frost Blast / Wind Blade / Earth Shaker) ยิงปุ่มเดียว; สลับ 0.2–0.3 วิ + ความร้อนเล็กน้อย; cooldown เวทที่ไม่ได้ถือนับต่อ; slow ซ้อนเต็ม ไม่มีขีดต่ำสุด; มี combo ธาตุ (คู่รอผู้ใช้ — Q225); Inferno กระสุนแยกนัดแต่น้อยลง ดาเมจต่อนัดสูงขึ้น; ไม่มีท่าไม้ตาย; ตัวเลขเริ่มจากสคริปต์ "Use" เดิม

### 3.4 ระบบต่อสู้
- **CC 10 ประเภท** (blind = ซ่อนกระสุน/ศัตรู), tenacity ค่าเริ่ม 0, super armor/อมตะ/ภูมิคุ้มกันเวท, dispel basic/strong (Q241–Q245)
- **Telegraph** ≥0.3–0.5 วิ ภาษารูปทรงเดียว; fake telegraph มีต้นทุน + เฉพาะบางตัว (แท็ก Trickster) (Q176, Q194, Q206)
- **Skill buffer:** เวลาที่เหลือ + ~0.1–0.15 วิ ในการสลับ/ร่าย/โดน CC/ท้าย cooldown (Q223, Q229–Q231)
- **คิวคำสั่งแบบ Dota:** กด Shift ค้าง, ไม่จำกัดเชิงเกม (มีเพดานทางเทคนิค), ปุ่มคิวบนจอสัมผัส/จอย, ไม่มี macro ภายนอก (Q247, Q259–Q263)
- **เลือกเป้า:** unit target + point target, เลือกเป้าที่มองไม่เห็นไม่ได้ (Q395, Q414); สกิลสะท้อนเดิมดูรายสกิล (Q394, Q396)

### 3.5 เกจความร้อน (overheat) — Q265, Q276–Q281, Q397–Q411
แต่ละสกิลกำหนดความร้อน (0 ได้) · หยุดลดช่วงสั้นหลังใช้สกิล · เพดานรายตัวละคร · overheat = silence ช่วงสั้น เดินได้ คิวคำสั่งเข้าคิวได้ · ล้างได้เฉพาะ strong dispel, tenacity ลดได้ไม่เกินครึ่ง, ภูมิคุ้มกันเวทกันไม่ได้, **ล้างแล้วเกจไม่ลด** · ตายรีเซ็ต · สกิลเพิ่ม/ระบาย/ขโมยความร้อนได้ · ร้านมียาเย็น/อัปเกรด · macro item ลดความร้อนปานกลาง · แสดงเกจตัวเอง+ศัตรูที่มองเห็น · **ข้อยกเว้นเดียว:** สกิลย้อนเวลาทั้งเกมย้อนความร้อนด้วย (Q512)

### 3.6 ระบบช่วยเล็ง (Q352, Q373, Q386–Q393)
- **ล็อกเป้า (lock-on)** คำนวณฝั่งเซิร์ฟ ทุกอุปกรณ์เท่ากัน ไม่มีต้นทุน ใช้ได้ทุกสกิล
- โหมดเล็งตำแหน่งปัจจุบัน / ดักทาง (ดักทางถูก bait ได้) ตั้งค่า+สลับระหว่างเล่น
- ล็อกหลุดเมื่อมองไม่เห็น/blind/เป้าแดชหรือวาร์ป; ศัตรูไม่รู้ว่าโดนล็อก
- **Magnetism** (เบนกระสุน) = ไอเทมในร้าน + สกิลบางตัว
- ⚠️ จุดบาลานซ์ที่ต้องดูจาก playtest: ล็อกเป้าแรงมาก (ไม่มีต้นทุน + ศัตรูไม่รู้)

### 3.7 เศรษฐกิจในแมตช์ (Q41, Q134–Q138, Q160, Q268–Q275)
รายได้: ฆ่า + assist + พื้นฐานตามเวลา + bounty (ลดเมื่อคนเดิมฆ่าคนเดิมซ้ำ) · ขายอัปเกรดค่าสถานะ + ของใช้ครั้งเดียว ไม่ขายอาวุธ · ซื้อที่จุดเกิด/ตอนรอเกิด/ร้านบนแผนที่ (ของพิเศษ) · ของอยู่จนจบแมตช์ · **Macro item:** ร้อยสกิลของตัวเองกดปุ่มเดียว ตามเวลาร่ายปกติ ติดตัวจนจบ ตั้งล่วงหน้าในบัญชี ไม่จำกัดจำนวน ศัตรูเห็น เซิร์ฟตรวจเนื้อหา (Q368) · ตัวเลขทั้งหมดผู้ใช้กำหนด · perk ก่อนแมตช์ผู้ใช้ออกแบบภายหลัง (Q40)

### 3.8 สกิลย้อนเวลาทั้งเกม (ตัวละครในอนาคต) — Q499–Q526
ย้อนทั้งเกม **5 วินาที** 1 ครั้ง/แมตช์ ใช้ได้ทุกเวลา (ครบเป้า kill ระหว่างร่าย = แมตช์จบ) · ร่าย 1–2 วิ ขัดได้ · สองทีมมีได้ ห้ามย้อนเกินจุดที่อีกฝ่ายย้อน, tick เดียวกันทีมคะแนนน้อยกว่าได้ก่อน · ไม่ย้อน: ตัวสกิล, ค่าระดับแมตช์, นาฬิกา, ผู้ควบคุมตัวละคร, ตัวจับ AFK · ช่วงที่ถูกลบเป็นไทม์ไลน์แยกใน replay ไม่นับสถิติ/XP · Lua เรียกไม่ได้

### 3.9 แผนที่ (Q24, Q302–Q310, Q87, Q191, Q198)
~40×24 ช่อง (ปรับได้), สมมาตรหมุน 180°, หลายโครงแบบ, กำแพงเฉียง 2–4/ฝั่ง, จุดเกิดเขตปลอดภัย, ร้านบนแผนที่ 2 จุดที่ปีก, พุ่มไม้+ลัง (ลังผู้ใช้ออกแบบ Q120–Q121), แผนที่แรกมาจากการเลือก ~20×24 ช่องของ legacy map แล้วหมุน, แผนที่ไม่สมมาตรใช้ในโหมดสบายๆ; ตรวจอัตโนมัติ: heatmap, ระยะสองฝั่ง, อัตราชนะฝั่ง (เกิน 3% แก้)

## 4. ภาพ เสียง และ UI

- **แนวภาพ:** sprite เดิม remaster 2x + แสง/เงา 2D, particle, bloom, hit-stop, squash/stretch; WebP/KTX2 + atlas (Q17, Q22)
- **ระดับกราฟิก** Low/Medium/High อัตโนมัติ (Q19); แอนิเมชันตัดสินด้วย spike เดือนแรก โดยนับต้นทุนสกินเป็นเกณฑ์ (Q20, Q550)
- **ความชัดเจน:** ทีมเรา=ฟ้า ศัตรู=แดง, กระสุนศัตรูเด่นกว่า, ธาตุแยกด้วยรูปทรง ขอบเป็นสีทีม, hitbox = ขนาดภาพ (ปุ่มแสดงได้), ขนาดกระสุนขั้นต่ำบนมือถือ, เสียงบอกเหตุ+ไอคอนคู่ (Q173–Q183, Q215)
- **UI:** เมนู HTML (Preact/Solid), HUD ใน Pixi; สไตล์ UI ผู้ใช้ออกแบบ (Q126, Q128); ≤2 คลิกถึงการเล่น (Q127)
- **ภาษา:** ไทย+อังกฤษ ในไฟล์ i18n → เพิ่ม ID/VI/JA/ES/PT-BR (Q26, Q113)

| เว็บ | ข้อความผู้เล่นเป็น text, CSP, token ใน httpOnly cookie, ตรวจ token กับผู้ให้บริการ |
